## Generation and precedence

`python docs/contracts/render.py --write` generates the marked endpoint/model/error/status/frontend/deferred/permission sections of API-CONTRACT and the related documents. Canonical OpenAPI/manifest/examples define Phase 1. source-baseline.json is read only as current-binary evidence for AST/DTO/served-document/runtime comparisons; it is not a second target. Advance it deliberately when actual code changes, without replacing missing Phase 1 work with legacy successes.

The historical planning validator now delegates to the Phase 1 gate when x-phase1 is present. Earlier 38-operation planning results/freezes remain historical records, not current conformance claims. Supersession notices on the earlier human contract/plan point to the current boundary.

Baseline success means no unreviewed drift. Strict completion also requires no source-only identity routes. Session-specific findings and OPEN-LOGOUT-PROOF are deferred, not silently declared solved. Only OPEN-READ-ORDER remains an active unresolved contract boundary.

No application handler/usecase/repository/frontend or SQL migration was changed. No database/container/server was started, credential created, email sent or deployment made. Real JWT verification, current database role changes, transaction races, private projections, token expiry/logout browser behavior, scheduling, file verification and SMTP need their implementation slices and acceptance tests.
